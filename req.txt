FreeLance3 - Requirements
=========================

This is a JavaScript (Node.js) project, so dependencies are installed with npm
from each folder's package.json, not with pip. This file lists everything you
need to run it.


SYSTEM REQUIREMENTS
-------------------
Node.js            >= 20 (developed on 22.x)
npm                >= 10
MongoDB            local instance or MongoDB Atlas cluster
BridgeKey          browser wallet extension (EIP-1193)
MSTC testnet coins for escrow deposits on MST Testnet (chain ID 91562037)
Groq API key       for AI skill verification (https://console.groq.com)
Cloudinary account for work submission file storage


INSTALL
-------
cd server     && npm install
cd client     && npm install
cd blockchain && npm install
